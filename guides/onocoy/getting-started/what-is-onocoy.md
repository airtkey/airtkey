# What is onocoy?

### What is onocoy?

onocoy is a decentralized GNSS correction network — built and maintained by people like you.

#### The Problem:

GPS alone is only accurate to about 3-5 meters. For many professional use cases — agriculture, surveying, autonomous vehicles — that's not precise enough.

#### The Solution:

RTK (Real-Time Kinematics) correction data can improve GPS accuracy down to 1-2 centimeters. onocoy builds a global network of RTK base stations — operated by independent miners.

#### How you earn:

1. You set up a GNSS base station at your location
2. Your station streams correction data to onocoy
3. onocoy sells this data to professional users
4. You earn ONO tokens as reward 💰

#### Key Facts:

* ⛓️ Built on Solana blockchain
* 🌍 Global network — the more stations, the better
* 🏠 Works from your home, garden or rooftop
* 💸 Passive income once set up
