# Solana Wallet Setup (Phantom)

### Solana Wallet Setup (Phantom)

onocoy rewards are paid in ONO tokens on the Solana blockchain. You need a Solana wallet to receive them. We recommend using Phantom — it's free, easy and widely used.

👉 Official onocoy wallet guide: [https://docs.onocoy.com/documentation/3.-become-a-miner/create-and-connect-a-wallet](https://docs.onocoy.com/documentation/3.-become-a-miner/create-and-connect-a-wallet)

#### Install Phantom Wallet:

1. Go to [https://phantom.app](https://phantom.app/)
2. Download the browser extension (Chrome, Firefox or Brave)
3. Click "Create New Wallet"
4. Write down your Secret Recovery Phrase — keep it safe offline!
5. Set a password for the extension

#### Connect Phantom to onocoy:

1. Log in to [https://console.onocoy.com/](https://console.onocoy.com/)
2. Go to your profile/settings
3. Click "Connect Wallet"
4. Select Phantom and approve the connection

> ⚠️ Never share your Secret Recovery Phrase with anyone! onocoy will NEVER ask for it.
