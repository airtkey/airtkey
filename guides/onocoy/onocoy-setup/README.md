# ⚙️ onocoy Setup

Before you can start mining with onocoy, you need to complete a few setup steps. Don't worry — it's straightforward and only needs to be done once.

This section walks you through:

* Creating your onocoy account
* Generating your NTRIP credentials
* Connecting your miner
* Setting up your Solana wallet to receive ONO rewards

> 💡 onocoy has excellent official documentation. Where possible, we link directly to their guides so you always have the most up-to-date information.
