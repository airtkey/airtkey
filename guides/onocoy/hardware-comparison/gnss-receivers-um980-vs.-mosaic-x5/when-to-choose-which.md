# When to Choose Which?

## 🏁 When to Choose Which?

Not sure which GNSS receiver is right for you? This guide helps you decide based on your situation.

***

### Quick Decision Tree

**💰 Budget under 200€?** \
└── ✅ Yes → **Go with UM980** \
└── ❌ No → keep reading...

**🏆 200€+ available & want maximum rewards?** \
└── ✅ Yes → **Go with Mosaic-X5** \
└── 🧪 Just testing? → **Start with UM980, upgrade later**

***

### Decision Table

| Your Situation                            | Recommended                       |
| ----------------------------------------- | --------------------------------- |
| Tight budget, just starting out           | UM980                             |
| Want to use ESP32 as controller           | UM980 only                        |
| Already have a Raspberry Pi               | UM980 → upgrade later             |
| Want maximum rewards from day one         | Mosaic-X5                         |
| Planning a professional / long-term setup | Mosaic-X5                         |
| Located in area with RF interference      | Mosaic-X5                         |
| Want to expand to multiple stations later | Start UM980, scale with Mosaic-X5 |

***

### 💰 Return on Investment

**UM980 Setup:**

* Lower upfront cost
* Good rewards from day one
* Solid long-term option

**Mosaic-X5 Setup:**

* Higher upfront cost (\~450€ more)
* Higher daily rewards due to better quality score
* Pays off over time through increased ONO earnings

> 📊 Based on real data, the Mosaic-X5 achieves \~18-23% higher quality scores than the UM980. 👉 See [Performance Metrics & Real Data](../../performance-and-optimization/)

***

### 🔄 Can I Upgrade Later?

**Yes!** Many miners start with the UM980 setup and upgrade to the Mosaic-X5 later.

The upgrade path is straightforward:

1. Keep your existing antenna and Raspberry Pi
2. Swap only the GNSS receiver module
3. Reconfigure the software
4. Enjoy higher rewards immediately

> 💡 Starting with UM980 is a smart move — you learn the system and upgrade when ready.
