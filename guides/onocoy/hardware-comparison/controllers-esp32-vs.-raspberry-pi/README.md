# Controllers: ESP32 vs. Raspberry Pi

## 🎛️ Controllers: ESP32 vs. Raspberry Pi

The controller is the brain of your mining station. It connects your GNSS receiver to the internet and sends your correction data to the onocoy network.

There are two main options — each with a different philosophy, price point and skill requirement.

***

### Quick Overview

| Feature              | ESP32                  | Raspberry Pi            |
| -------------------- | ---------------------- | ----------------------- |
| Price                | \~5-15€                | \~35-80€                |
| Setup difficulty     | Easy                   | Moderate                |
| Power consumption    | Very low (\~0.5W)      | Moderate (\~3-5W)       |
| Remote access        | Limited                | Full SSH / VNC          |
| Compatible receivers | UM980 only             | UM980, Mosaic-X5        |
| OS / Software        | Firmware (pre-flashed) | Linux (Raspbian)        |
| Headless operation   | ✅ Yes                  | ✅ Yes                   |
| Best for             | Beginners / Budget     | Pro / Remote Management |

***

### What You'll Find Here

⚡ **Pros & Cons Overview** A detailed breakdown of both controllers — what they do well and where they fall short.

🟡 **ESP32 – Budget & Simple** The affordable plug-and-play option. Perfect for your first mining station.

🔵 **Raspberry Pi – Pro & Remote** The flexible Linux-based option. Ideal for serious miners who want full control.
